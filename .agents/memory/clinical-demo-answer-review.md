description: Publication boundary for medical model answers and marking schemes in the MedEazy public demo.
---

Draft medical model answers and marking schemes for review, but do not publish them to the public demo until the user approves the content.

**Why:** The existing demo questions had no authored answers. When offered the choice, the user asked for drafts for review rather than authorizing immediate publication of invented teaching material.

**How to apply:** When adding or revising demo SAQ answer content, keep drafts separate from live public answers pending explicit approval. Once approved, publish the approved wording and verify the demo returns it without AI generation.
